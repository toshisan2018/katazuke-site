# GSC インデックス登録リクエスト チェックリスト

対象：`katazuke.amt-eco.com`（Google Search Console / URL検査）

## 使い方
1. GSC でプロパティ `katazuke.amt-eco.com` を開く
2. 上部の **URL検査** に下の各URLを1つずつ貼る → Enter
3. 「インデックス登録をリクエスト」をクリック → 「リクエスト済み」を確認
4. 完了したら下表の「済」欄に `x` を入れて、実施日を記入
5. ⚠️ 1日の上限（十数件程度）に達したら翌日に残りを実施

> ヒント：リクエスト前に各URLをブラウザで開き、404でないことを確認すると確実です。
