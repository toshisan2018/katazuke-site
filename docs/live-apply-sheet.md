# ライブ反映 コピペシート（タイトル・H1・メタディスクリプション）

対象：`katazuke.amt-eco.com`（WordPress）
用途：各固定ページに、新タイトル・見出しH1・メタディスクリプションを反映するためのコピペ元。
- **手貼りでもOK**（接続不要）。
- WordPress接続で代行する場合も、このシートを正とします。
- すべて確定情報のみ（順位・料金・実績・許認可番号は不記載）。

## 反映先の対応（どこに貼るか）
| 項目 | 反映先 |
|---|---|
| タイトル | SEOプラグイン(Yoast)の「SEOタイトル」。プラグイン無しなら固定ページの「タイトル」 |
| H1 | 本文（カスタムHTML）の `<h1>…</h1>` を置換。※7ページのみ変更あり（下表「H1」） |
| メタディスクリプション | Yoastの「メタディスクリプション」。プラグイン無しは設定不可（Yoast導入が必要） |

> ヒント：Yoastは各固定ページ編集画面の下部「Yoast SEO」欄で、スニペット編集 → タイトル／メタディスクリプションを入力。

## 作業手順（手貼りの場合・1ページずつ）
1. WordPress管理画面 →「固定ページ」→ 対象ページを「編集」
2. （★7ページのみ）本文の「カスタムHTML」ブロックで `<h1>…</h1>` を新H1に置換
3. ページ下部の「Yoast SEO」欄 → スニペット編集
   - 「SEOタイトル」に上記タイトルを入力
   - 「メタディスクリプション」に上記メタを入力
4. 「更新」
5. 公開ページで、タブ名（title）とページソースの `<meta name="description">` を確認

## 備考
- H1の変更はリポジトリ（`assets/pages/*.html`・`build_pages.py`）には既に反映済み（PR #7）。ライブへは本シートで反映。
- メタディスクリプションにはYoast（またはSEOプラグイン）が必要。未導入なら導入後に入力。
