## 適用方法（どこで設定するか）
WordPress（AI Engine／テーマ）での反映先は、構成により次のいずれか：
1. **SEOプラグイン（AIOSEO / Yoast 等）**を使っている場合 → 各ページの「スニペット編集」で title / description を上書き（推奨）
2. プラグイン未使用の場合 → 各固定ページの「ページタイトル」と、テーマのメタ設定／抜粋（excerpt）に反映
3. リポジトリ運用で揃える場合 → `assets/build_pages.py` の各ページ `title` を上記提案に更新し、`python assets/build_pages.py` で再生成（※生成物の直接編集はしない、という既存ルールに沿う）

> 注意：どの方法でも**ライブ反映は手動（またはWordPress接続）**が必要です。本書はリポジトリ上の提案で、
> 直接ライブに反映されるものではありません。

## 反映後の確認
- 各ページを開き、ブラウザのタブ名（title）が提案どおりか

- 数日後、GSC「検索パフォーマンス」でクリック率（CTR）の変化を確認
