# 対応事例（施工実績）記入シート

対応事例ページ `/jirei/` に載せる **実際の案件** を10件ぶん記入してください。
記入いただいた内容を `assets/jirei-data.json` に反映し、`confirmed` を `true` にすると公開対象になります。

> **なぜ記入が必要か**
> 実在しない案件を「実績」として掲載すると、お客様への虚偽表示になります。
> また Google は 2024 年以降、実体のない水増しコンテンツ（スケーリングされたコンテンツの不正使用）を
> 明確に評価対象外・または低評価としており、SEO にも逆効果です。
> **実際にやった仕事を1件ずつ書くのがいちばん強い** ので、お手数ですがご記入をお願いします。

## 書いてはいけないこと

- お客様のお名前・番地・町名・電話番号
- 顔・表札・車のナンバー・郵便物が写った写真
- 「満足度No.1」「地域最安」など、根拠を示せない表現（景品表示法の優良誤認・有利誤認にあたるおそれ）
- いただいていないお客様の声（創作した口コミ）
- 一般廃棄物の「収集運搬」という表現（当社は許可を持たないため。買取・片付け搬出／提携許可業者へ委託、と書く）

## 写真について

- 1件に1〜2枚あると効果的です。**ビフォー／アフターの2枚**がもっとも伝わります。
- スマホ撮影でかまいません。横向き（横長）で撮ってください。
- お客様に**掲載の許可**をいただいたものだけお使いください。
- ファイル名は `jirei-01-before.jpg` のように連番で。こちらで軽量化（WebP化）してアップします。

## 公開までの流れ

1. このシートに記入 → 鈴木（担当）へ
2. `assets/jirei-data.json` に反映し `confirmed: true` に変更
3. 写真を軽量化して WordPress メディアへアップ
4. `python assets/build_pages.py && python assets/publish_bundle.py` → 管理画面から公開
5. ナビ・フッターに「対応事例」を表示（現在は非表示）
6. Search Console で `/jirei/` のインデックス登録をリクエスト

> 3件記入いただいた時点で公開できます（10件そろうまで待つ必要はありません）。
> 件数が増えるたびに追記・再公開してください。
