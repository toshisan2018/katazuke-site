# UIコンポーネント（ドロップイン部品）

サイト改善（`docs/improvement-plan.md` フェーズ1）用の、貼るだけで使える自己完結HTMLです。
既存の生成処理（build_pages.py）は変更しません。ライブへは「カスタムHTML」ブロックで反映します。

| ファイル | 用途 | 貼り先の目安 |
|---|---|---|
| `sticky-cta-bar.html` | スマホ追従CTAバー（電話／無料見積り） | 全ページ共通（フッター用ウィジェット等） |
| `comparison-table.html` | AIO/SEO向け「一貫対応」比較表 | トップ・家の片付け・残置物撤去 などの本文 |

## 共通仕様
- インラインCSSで自己完結（貼り先テーマのCSSに影響されにくい）。
- 文言・電話番号・リンク先は確定情報のみ（料金・実績・口コミ・数値は不記載）。
- ブランド黄（#f7b500）＋スレート（#2f3a41）で統一。

## 注意
- `sticky-cta-bar.html` はスマホ幅(〜768px)でのみ表示。PCでは出ません。
- 全ページに出したい場合は、テーマのフッター（全ページ共通で読み込まれる場所）に1回だけ設置するのが理想です。
- これらはリポジトリ上の部品です。ライブ反映は手動（またはWordPress接続時に代行）。
