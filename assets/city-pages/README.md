## 作り方
1. `_template.html` をコピー
2. `{{CITY}}` を市名（例：焼津市）に全置換
3. `{{CITY_INTRO}}` を**その市ならではの一言**に差し替え（下記の注意）
4. WordPressで新規固定ページを作成し、本文に「カスタムHTML」ブロックで貼り付け
5. パーマリンク（slug）を設定：例 `/fujieda/`、`/yaizu/` など（`/area-fujieda/` でも可。サイト内で統一）
6. 公開後、ナビやフッター、`/area/`（対応エリア）ページから各市ページへ内部リンク（`docs/internal-linking.md` 参照）

## 重要（SEO：重複コンテンツを避ける）
- **市ごとに本文を必ず変える**こと。`{{CITY_INTRO}}` だけでなく、可能なら「対応できること」の例や質問も市に合わせて少し調整。
- コピペで市名だけ変えた量産ページは、Googleに重複と判断され逆効果になり得ます（一般的なSEO原則）。
- 料金・実績・口コミは**入れない**（確定データができてから別途）。
