# 株式会社AMT 事業別サブドメインサイト テンプレート

このリポジトリは、株式会社AMTが事業ごとに立てるサブドメインサイト（例：解体＝`kaitai.amt-eco.com`）を
作るための共通テンプレートです。解体工事サイト（kaitai-site）の構成をもとに、
解体事業に固有の内容（文言・画像・色・許認可番号など）を除いて汎用化しています。

対象となる事業例：解体、片付け、システム開発、通販 など、AMTがamt-eco.comのサブドメインで
展開する事業サイト全般。

---

## 使い方（新しい事業サイトを作る手順）

1. GitHubでこのリポジトリを開き、**「Use this template」→「Create a new repository」** で複製する
   （例：片付け事業なら `katazuke-site`）
2. 複製したリポジトリの中で、下記ファイルの `【　】` で囲まれた部分を、その事業の内容に書き換える
   - `index.html` … 色（CSS変数）、事業名、キャッチコピー、サービス内容、TEL／メール、会社概要欄など
   - `assets/build_pages.py` … 冒頭の `CONFIG` ブロック（事業名・ドメイン・TEL・メール・ナビ項目など）
   - `site-handover-template.md` … 「確定事項」表（会社名・所在地・TEL・許認可・デザイン・対応エリアなど）
   - `image-brief-template.md` / `additional-images-template.md` … ブランドカラー・事業内容
3. 下層ページが必要な場合は `assets/build_pages.py` の `PAGES` 部分に事業のページを追記し、実行して
   `assets/pages/` に生成する（サンプルとして1ページ分のひな形が入っています）
4. 画像は `画像制作指示書` に沿って用意し、`assets/images/` に配置する
5. 公開前に、下記「必ず確認すること」を必ずチェックする

## フォルダ構成

```
.
├── index.html                      # TOPページ（単一HTML、色・文言はプレースホルダー）
├── assets/
│   ├── build_pages.py              # 下層ページ生成スクリプト（CONFIG部分を書き換える）
│   ├── pages/                      # ↑の生成出力先（空・.gitkeepのみ）
│   └── images/                     # サイト用画像の置き場（空・.gitkeepのみ）
├── snapshot-live/                  # 公開中ページのスナップショット置き場（運用開始後に使用）
├── site-handover-template.md       # 引継ぎ書テンプレート（確定事項・サーバー環境・作業指示）
├── image-brief-template.md         # 画像制作指示書テンプレート（AI画像生成・デザイナー発注用）
├── additional-images-template.md   # 追加画像リストテンプレート（企画リスト）
└── .gitignore
```

SEO監査を行った場合は、リポジトリ直下に `audit-YYYYMMDD/`（実施日）フォルダを作り、
その中に監査結果・改善指示書を保存する運用とする（本テンプレートには含めていない）。

## ⚠️ 必ず確認すること（推測で進めない）

- **許認可番号・保有資格は事業ごとに異なる。** 元になった解体工事サイトの「静岡県知事（登8）第1372号」
  などの解体専用の番号は、他事業のサイトに**絶対に転記しない**。その事業で実際に必要・保有している
  許認可のみを、社長に確認のうえ記載する。
- **配色・キャッチコピー・実績・料金は事業ごとに決める。** 「解体専用」の赤×黄テーマをそのまま流用しない。
- ファイルを作成・編集する前に、記入内容を一覧で社長に確認してから作業する。
- 「業界最安」「施工実績◯件」など、根拠のない表現は使わない。
